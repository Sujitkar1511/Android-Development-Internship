## 🚀 How to Run the Projects

1. **Clone the Repository:**
   `ash
   git clone https://github.com/Sujitkar1511/Android-Development-Internship.git
   `

2. **Open in Android Studio:**
   - Launch **Android Studio**.
   - Select **Open an existing project**.
   - Navigate to the specific project folder (e.g., SimpleCalculator or CollegeWebViewApp).
   - Allow Gradle to sync and build the project.

3. **Run the App:**
   - Select an Android Virtual Device (Emulator) or connect a physical device with USB Debugging enabled.
   - Click **Run** (Shift + F10).
