# recycleBing - Friend Request RecyclerView App

An Android application developed using **Kotlin** and **RecyclerView** that displays a vertical list of Friend Requests with mutual friends count and interactive buttons.

## 📱 Features
- Vertical scrolling list using **RecyclerView** and **CardView**.
- Custom data adapter (`FriendRequestAdapter`) and data model (`FriendRequest`).
- Interactive UI layout displaying person names, mutual friends count, and action buttons (`Confirm`, `Delete`).
